# 🧸 Бяцхан Дэлгүүр

Taobao / Pinduoduo-оос **хүүхдийн бараа** татаж, **зөвхөн олон зарагдсан, хэрэглэгчдэд таалагдсан** барааг
**таны өөрийн амтаар** шүүж, Монгол хэрэглэгчдэд төгрөгөөр зардаг web app (HIbox маягийн, хүүхдийн бараанд төвлөрсөн).

## Ажлын урсгал

```
Taobao / PDD  ──▶  Импорт  ──▶  Шалгуур + Амт (оноо)  ──▶  Админ батална  ──▶  Дэлгүүрт гарна
                                                                                   │
Хүргэлт  ◀──  Монголд ирсэн  ◀──  Карго  ◀──  Хятадаас захиална  ◀──  Төлбөр орсон  ◀──  Захиалга
```

1. **Импорт** — тохируулсан хайлтын үгсээр (`儿童玩具`, `童装` …) бараа татна.
2. **Хатуу шүүлтүүр** — доорх аль нэгэнд таарахгүй бол хасна:
   - хүүхдийн бараа мөн эсэх (`儿童`, `宝宝`, `婴儿` … үгс)
   - хориотой үг (`成人`, `磁力珠` гэх мэт аюултай/хэрэггүй бараа)
   - хамгийн бага борлуулалт, үнэлгээ, эерэг сэтгэгдлийн хувь, сэтгэгдлийн тоо, үнийн хязгаар
3. **Оноо (0–100)** = борлуулалт + үнэлгээ + эерэг сэтгэгдэл + **таны амт**, жин бүрийг өөрөө тохируулна.
   Амтыг `木制:15`, `纯棉:15`, `塑料:-8` маягаар үг тус бүрт жин өгч тодорхойлно; дуртай дэлгүүрт нэмэлт оноо.
4. Босго оноо давсан бараа **"Хүлээгдэж буй"** жагсаалтад орно. Та монгол нэр, жинг нь засаад **Гаргах** дарна
   (эсвэл `autoApprove`-г асааж шууд гаргана).
5. **Үнэ** = `¥ × ханш × (1 + ашиг%) + жин × карго/кг + тогтмол шимтгэл`, 100₮-өөр дээш бүхэлчилнэ.
6. Хэрэглэгч сагслаад захиална (нэр, утас, хаяг, QPay/данс). Захиалгын код + утсаар төлвөө шалгана.
7. Админ төлбөр орсныг тэмдэглэхэд **"Хятадаас авах жагсаалт"** бараа+сонголтоор нэгтгэгдэж, Taobao/PDD линктэй гарна.

## Ажиллуулах

Node.js 22.13+ шаардлагатай (SQLite нь Node-д суурилагдсан).

```bash
npm install
ADMIN_TOKEN=нууц_үг npm start
# Дэлгүүр: http://localhost:3000
# Админ:   http://localhost:3000/admin/   (баруун дээд буланд ADMIN_TOKEN-оо оруулна)
```

Анхдагчаар жишээ (mock) өгөгдөл ашиглана. Анх асаахад 12 жишээ бараа автоматаар дэлгүүрт гарна.
Шинэ бараа татахын тулд: Админ → **Бараа** → **"Taobao/PDD-ээс шинээр татах"** → барааг **Гаргах**.

```bash
npm test                          # тест
npm run import -- 儿童玩具 童装    # командын мөрөөс импорт (cron-д тохиромжтой)
```

## Бодит Taobao / Pinduoduo өгөгдөл холбох

Taobao, PDD нь нээлттэй хайлтын API шууд өгдөггүй. Сонголтууд:

- **Taobao Open Platform / 淘宝联盟**, **多多进宝 (PDD affiliate)** — албан ёсны, бүртгэл шаардана
- **Гуравдагч data provider** (`item_search` маягийн API санал болгодог үйлчилгээнүүд)

Provider-ийнхаа хайлтын URL-ийг тохируулна (`{q}`, `{page}` орлуулагдана):

```bash
PRODUCT_SOURCE=http \
TAOBAO_SEARCH_URL='https://provider.example/taobao/item_search?q={q}&page={page}&key=XXX' \
PDD_SEARCH_URL='https://provider.example/pdd/item_search?q={q}&page={page}&key=XXX' \
npm start
```

Provider бүрийн JSON бүтэц өөр тул `src/sources/http.js` дахь `normalize()`-ийг өөрийнхөө хариунд тааруулна.
Борлуулалт (`sales`), үнэлгээ (`rating`), эерэг хувь (`positive_rate`), сэтгэгдлийн тоо (`review_count`) ирэх нь
шүүлтүүрт хамгийн чухал.

## Орчны хувьсагч

| Хувьсагч | Анхдагч | Тайлбар |
|---|---|---|
| `PORT` | `3000` | |
| `DB_PATH` | `data/shop.db` | SQLite файл |
| `ADMIN_TOKEN` | `changeme` | Админ нэвтрэх нууц үг — **заавал солино** |
| `PRODUCT_SOURCE` | `mock` | `mock` эсвэл `http` |
| `TAOBAO_SEARCH_URL`, `PDD_SEARCH_URL` | | `http` горимд |

Шалгуур, амт, ханш, ашгийн хувь зэргийг админ самбарын **"Шалгуур ба амт"** табаас өөрчилнө
(анхны утгууд `src/config.js`-д). Хадгалахад бүх барааны оноо дахин бодогдоно.

## Бүтэц

```
src/
  config.js        тохиргоо, анхны шалгуур/амт/үнэ
  curation.js      шүүлтүүр ба оноо (цэвэр функц)
  pricing.js       ¥ → ₮ үнэ
  importer.js      эх сурвалжаас татах, шүүх, хадгалах
  sources/         mock.js (жишээ), http.js (бодит API adapter)
  app.js           REST API (нийтийн + /api/admin)
public/            дэлгүүр (index.html, app.js) ба admin/
test/              node:test тестүүд
```

## Дараагийн алхмууд

- **QPay** API холбож төлбөрийг автоматаар баталгаажуулах (одоо админ гараар "Төлбөр орсон" болгоно)
- Хятад гарчиг, тайлбарыг монгол руу автоматаар орчуулах (LLM ашиглаж болно)
- Барааны зургийг өөрийн storage руу хуулах (Taobao/PDD зургийн hotlink хаагдах магадлалтай)
- Сэтгэгдлийн текстэд дүн шинжилгээ хийж (жишээ нь "чанар муу", "үнэртэй") амтын оноонд нэмэх
- Импортыг өдөр бүр cron-оор ажиллуулж борлуулалт/үнийг шинэчлэх
